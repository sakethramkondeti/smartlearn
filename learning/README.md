# Learning Content & Knowledge Graphs — Cognix

Contains curricula definitions, concept dependency DAGs (Directed Acyclic Graphs), lesson blueprints, and IRT-calibrated problem sets.

## Structure
- `graphs/`: Concept dependency ontologies in JSON / YAML format specifying prerequisite relationships.
- `curriculums/`: Course structures, learning outcomes, and module definitions.
- `question_banks/`: Categorized question banks with difficulty parameters ($b$), discrimination ($a$), guessing ($c$), and detailed misconception tags.
